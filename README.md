## The main idea

**Keep the installed cooling functions.** If the available cooling cannot sustain production, a *removable* auxiliary arrangement may couple the existing cold-water basin to a separate outdoor cold-water buffer through a suitable heat exchanger. The two fluids stay separate.

The concept does **not** imply that any particular pump, heat exchanger or outdoor tank has been approved for installation. Outdoor winter air can cool a buffer gradually; this is not proof of continuous two-press cooling.

## How to interpret the status labels

| Label | Meaning |
|---|---|
| **INSTALLED** | Seen in the established factory system, but not necessarily performing at full capacity now. |
| **ON SITE / CANDIDATE** | A physical item is present; its suitability and assignment are still to be verified. |
| **ORDERED / EMPTY** | Order has been sent; delivery, filling, acceptance and actual usable volume are separate checks. |
| **TO SELECT** | Equipment or work proposed but not yet validated or purchased. |
| **UNKNOWN** | Evidence is currently insufficient. Please correct or add verified information. |
